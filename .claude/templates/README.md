# Templates — Índice

Plantillas estandarizadas para documentos que se generan repetidamente en cualquier proyecto.

| Plantilla | Uso |
|---|---|
| [`ADR.md`](./ADR.md) | Architecture Decision Record — documentar una decisión arquitectónica ya tomada |
| [`RFC.md`](./RFC.md) | Request for Comments — proponer un cambio significativo antes de implementarlo |

## Próximas plantillas (Milestone 12)

```
README.md          (plantilla de README de proyecto, distinta de estos índices de carpeta)
BUG_REPORT.md
ISSUE.md
PULL_REQUEST.md
OPENAPI.md
```
