# Prompts — Índice

Prompts reutilizables **globales**, aplicables a cualquier dominio tecnológico. Cada uno define un flujo de instrucciones concreto para una tarea recurrente (revisión, refactor, generación de tests, debugging, diagnóstico de rendimiento).

| Prompt | Cuándo usarlo |
|---|---|
| [`review.md`](./review.md) | Revisión arquitectónica de un módulo o Pull Request |
| [`refactor.md`](./refactor.md) | Planificar y ejecutar un refactor seguro paso a paso |
| [`generate-tests.md`](./generate-tests.md) | Generar una suite de tests siguiendo la pirámide de testing |
| [`debug.md`](./debug.md) | Depuración sistemática de un fallo |
| [`performance.md`](./performance.md) | Diagnóstico de rendimiento antes de optimizar |

Ver también [`../checklists/`](../checklists/) (checklists que estos prompts referencian al finalizar) y [`../recipes/`](../recipes/) (guías paso a paso específicas por tecnología, más concretas que estos prompts genéricos).
