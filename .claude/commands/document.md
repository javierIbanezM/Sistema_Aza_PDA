# /document

## Qué hace

Genera la documentación técnica correspondiente al tipo de cambio realizado — nunca un tipo de documento genérico sin criterio de cuál corresponde.

## Invoca

- Guía general: [`../knowledge/architecture/technical-documentation.md`](../knowledge/architecture/technical-documentation.md) para decidir qué tipo de documento corresponde.
- Decisión arquitectónica de alto impacto → [`../templates/ADR.md`](../templates/ADR.md).
- Propuesta de cambio significativo antes de implementar → [`../templates/RFC.md`](../templates/RFC.md).
- Cambio de contrato de API → actualización de OpenAPI (ver [`../knowledge/architecture/openapi.md`](../knowledge/architecture/openapi.md)).
- Cambio de cómo se instala/usa el proyecto → `README.md` del propio proyecto.

## Cuándo usarlo

Como parte del cierre de cualquier tarea que corresponda a uno de los casos anteriores — ver `CLAUDE.md` sección 0.1, paso 13 (documentar es parte del flujo estándar, no un extra opcional).

## Equivalente manual

Consultar [`../knowledge/architecture/technical-documentation.md`](../knowledge/architecture/technical-documentation.md) directamente.
