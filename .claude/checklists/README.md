# Checklists — Índice

Checklists de verificación **globales**, organizadas por tema (no por dominio tecnológico). Se ejecutan antes de dar una tarea por terminada.

| Checklist | Cuándo ejecutarla |
|---|---|
| [`architecture.md`](./architecture.md) | Cualquier tarea que implique una decisión de diseño o arquitectura |
| [`security.md`](./security.md) | Cualquier tarea con implicaciones de seguridad |
| [`performance.md`](./performance.md) | Cualquier tarea de diagnóstico u optimización de rendimiento |
